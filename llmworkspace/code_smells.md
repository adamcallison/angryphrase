## Resolved

- **P2** (resolved 2026-09-08, F+B design): dead pick-catch removed + drop-read failure surfaced per NFR-12. `report-import-read-failure` intent added to BOTH Builder + Player unions (ambiguous-kind routing by `state.route`); each reducer mirrors its existing parse-reject surface (Builder: error toast event, state unchanged; Player: `lastImportError` + toast — banner and toast, same as parse rejects). Drop IO moved behind the port: `FilePickPort.readDroppedFile(file: File): Promise<string | null>` (never-throw §3.7, single warn site, null = genuine failure — drops have no cancel path). `FilePicker.svelte` fully presentational: props `{ label, pick, onpick, ondropfile }`, zero IO/catch/console. Facade actions `BuilderToolbarActions.importDroppedFile` / `PlayerImportScreenActions.importDroppedFile` read via the port and dispatch native-dialect intents (`request-import-puzzle` / `import-puzzle` on success, `report-import-read-failure` on null) — no facade-dispatch narrowing bypassed, no AppIntent. AD amended (§1.3 ×2 rows, §2.1 line 205, §3.7 `FilePickPort`, §4.3 + §4.4 unions, §8.9 + §8.9a, §7 line 314 + BuilderToolbar/ImportScreen rows). Superseded design (AppIntent + `onreaderror` prop) + rationale recorded in `console_log_audit.md` (P2). CI green at landing: 80 test files / 1093 tests, typecheck 0/0, lint + madge clean.
- **P3** (resolved 2026-09-08, W1 design): autosave write failures surfaced. `StoragePort` writes widened `void` → `Error | null` (silent, non-`Error` throws coerced; warn moved out of the port); loads keep the benign-null read contract. `createAppStore` now constructs the `PersistenceScheduler` internally from `ports.storage` (W1 — kills the scheduler↔store construction cycle and the latent storage-injection mismatch; `options.persistenceDebounceMs`). The scheduler stays mechanical, reporting every attempted write via `onWriteResult(slice, err)`; the appStore holds per-slice latches: warn once + `report-builder-save-failure` / `report-player-save-failure` error toast on the first failure of an episode, re-armed by the next successful write in that slice, write-driven re-toast at `options.saveFailureRetoastMs` (default 60 s) while failing. Clear failures arm the same latch (builder stale blob self-heals on next save; failed keyed player clear resurrects only on re-import of that puzzle — accepted edge). Also landed a re-entrant-dispatch guard (nested dispatch joins the active work-queue — F6 fix generalized; prevents lost-update when a failed clear fires inside a dispatch batch). `InMemoryStoragePort` gained one-shot `nextWriteError`. ~30 test call sites lost their scheduler argument. AD amended (§1.3, §2.1 ×4, §2.2, §2.4, §3.7, §4.1, §4.5, §7). Full audit: `console_log_audit.md` (P3). CI green: 80 test files / 1114 tests.
